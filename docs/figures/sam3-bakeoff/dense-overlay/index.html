SAM3 per-slice masks merged into one dense per-frame labelmap

Every neuron's per-slice mask remapped from its crop into a common scale-8 frame and stacked by neuron id (0 = background). Left: raw merge (a pixel claimed by 2+ neurons keeps the higher-id neuron). Right: optional argmax arbitration (contested pixels reassigned to the nearest mask centroid). No claim that arbitration is better here; it is shown so the effect is visible. Validating against the merge metric is a TODO. No model runs.
